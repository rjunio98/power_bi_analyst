# 📊 Repositório Power BI

Este repositório reúne projetos desenvolvidos em **Power BI**, com foco em:

- Criação de dashboards interativos
- Análise de dados de diferentes fontes
- Exploração de métricas e indicadores de negócio
- Estudos e experimentos em visualização de dados

---

## 🚀 Objetivo
O objetivo deste repositório é centralizar projetos de análise de dados e visualização, servindo como portfólio e laboratório de aprendizado em Power BI.

---

## 🛠️ Tecnologias Utilizadas
- Power BI Desktop
- Excel / CSV
- Git & GitHub para versionamento

---

## 📌 Como usar
